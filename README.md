# Customer-Management-System
Customer Management System

A full-stack Customer Management System built using Java, Spring Boot, PostgreSQL, HTML, CSS, and JavaScript. The application demonstrates RESTful API development with complete CRUD functionality and a responsive frontend that communicates with the backend using the Fetch API.

Features
--------
Create new customers
View all customers
Update customer details
Delete customers
Partial update using PATCH API
Responsive user interface
PostgreSQL
RESTful API architecture
Spring Data JPA with Hibernate
